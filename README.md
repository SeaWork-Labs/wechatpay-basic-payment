# wechatpay-basic-payment

微信支付基础支付接入助手：支付、退款与账单、分账、商户进件、开户意愿确认。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/wechatpay-basic-payment#v1.0.1 --skill wechatpay-basic-payment
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill wechatpay-basic-payment
```

## 内容

技能正文在 `skills/wechatpay-basic-payment/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/wechatpay-basic-payment/payload/`，不要反向同步。版本以 git tag 为准。
